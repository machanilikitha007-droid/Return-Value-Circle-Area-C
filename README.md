# Return Value in C

This program demonstrates how a function calculates a value and returns
the result to the calling function.

## File

circle_area.c

## Concepts Used

- Function return value
- Function parameter
- Function call
- Floating-point values

## How to Run

gcc circle_area.c -o circle_area
./circle_area

## Sample Output

Enter radius: 5
Area of Circle = 78.54
